# IELTS Cozy Design Skill

Read `DESIGN.md` and `design-tokens.json` before any UI decision.

## Required behavior

1. Treat `design-tokens.json` as canonical values and `DESIGN.md` as usage rules.
2. Match mockup language: bright canvas, ink content, blue primary action, pastel learning contexts, rounded cards, editorial whitespace.
3. Use semantic tokens. Do not hard-code visual values in feature code.
4. Keep UI calm and mobile-first. Prioritize reading, listening controls, answer entry, and progress clarity.
5. Include keyboard focus, minimum touch target, empty/loading/error states, and reduced-motion behavior.
6. Propose an ADR before changing token architecture, typography family, semantic colors, or component patterns.

## MVP context

Vocabulary uses lemon surface. Grammar uses peach surface. Listening uses ice surface. All use ink text and blue actions.
