# GlowUp IELTS — Product Overview

## 1. Product idea

GlowUp IELTS is mobile-first web app for Vietnamese IELTS learners. Product turns a large goal (target band) into daily practice loops across Listening, Reading, Writing, Speaking, vocabulary, and full mock tests.

Core promise: learner always knows what to practice next, why it matters, and whether progress is moving toward target band.

## 2. Target users

| Segment | Need | Product response |
|---|---|---|
| Grade 10–12 student | Study consistently without feeling overwhelmed | Short daily quests, streaks, focused practice |
| University student | Reach 6.0–7.0 for graduation/scholarship | Target-band plan, timed mock tests, weak-skill insights |
| Busy working learner | Practice in small time windows | 5–20 minute lessons, saved progress, flexible planner |

## 3. Jobs to be done

- When I have an IELTS target, help me turn it into daily actions I can finish.
- When I practice, show feedback specific enough to fix next attempt.
- When I lose momentum, help me restart without shame or a complex plan.
- When test day approaches, simulate real exam conditions and show readiness.

## 4. Product goals

1. Establish daily practice habit.
2. Improve measurable skill performance.
3. Build test familiarity and confidence.
4. Give learner clear, honest band-readiness signals.

## 5. North-star metric

**Weekly qualified practice sessions per active learner**

Qualified session: completed skill activity or mock-test section with at least 5 minutes engaged time. It measures habit and real learning better than sign-ins alone.

Supporting metrics:

- Onboarding completion rate
- Day-7 retention
- Daily quest completion rate
- Mock-test completion rate
- Band-score improvement after 4 weeks
- Writing/Speaking feedback review rate

## 6. Experience principles

- One obvious next action on every screen.
- Small wins first: 5–20 minute tasks before long sessions.
- Feedback is supportive, direct, and actionable.
- Gamification celebrates progress, never blocks learning.
- Mobile-first, distraction-light, accessible contrast and readable type.

## 7. Visual direction: Gen Z / Gen Alpha

- Bright editorial color blocks, soft gradients, playful stickers and motion accents.
- Large type, rounded cards, clear hierarchy, minimal dense tables on mobile.
- Personal progress feels like a game dashboard: XP, streak, quests, milestones.
- Motion remains optional and respects reduced-motion settings.
- Tone: friendly, concise, encouraging; no forced slang or guilt messaging.

## 8. Release strategy

### Phase 1 — Learning MVP

Onboarding, dashboard, all four skill practice types, vocabulary review, daily plan, progress tracking, basic mock test, manual/rule-based feedback.

### Phase 2 — Feedback depth

AI-assisted Writing/Speaking feedback, transcript analysis, adaptive recommendations, richer question bank, notifications.

### Phase 3 — Exam ecosystem

Teacher/coach workspace, study groups, paid plans, live classes, verified score reporting.
