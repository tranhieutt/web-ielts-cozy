# Domain Glossary

- **Learner:** Anonymous or registered user with one Auth UUID.
- **Attempt:** One submitted or in-progress exercise session.
- **Content version:** Immutable published revision used by an attempt.
- **Deck:** Grouped vocabulary cards.
- **Review event:** Learner rating of a vocabulary card that updates next review date.
- **Exercise:** Grammar or Listening activity with questions and answer keys.
- **Qualified activity:** Completion that can earn XP and count toward streak.
