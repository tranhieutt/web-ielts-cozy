# Source of Truth

Read in this order:

1. `index.html` for deployed visual layout and interaction behavior
2. `docs/product/PRODUCT_SPEC.md` for product requirements beyond visible behavior
3. `DESIGN.md` and `design-tokens.json` for UI rules and token values
4. `docs/architecture/ARCHITECTURE.md`
5. `docs/architecture/DECISION_LOG.md`
6. Relevant ADR
7. Assigned task

For screen behavior, `index.html` wins until product owner changes it. Conflicts involving data, privacy, architecture, or unimplemented product behavior must be resolved by Claude or product owner.
