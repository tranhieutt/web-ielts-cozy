# Source of Truth

1. `docs/product/PRODUCT_SPEC.md`
2. `DESIGN.md` and `design-tokens.json` for UI work
3. `docs/architecture/ARCHITECTURE.md`
4. `docs/architecture/DECISION_LOG.md`
