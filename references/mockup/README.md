# Mockup Reference

This directory stores original prototype material only.

```text
ielts-cozy.mockup.html  Original interactive mockup
support.js              Mockup runtime helper
uploads/                Mockup images referenced by the HTML
```

Rules:

- Do not import these files into production application code.
- Use them to validate information architecture, interaction intent, and visual language.
- Keep `uploads/` relative to the HTML so the reference remains viewable.
- New product assets belong in the application/content storage workflow, not here.
